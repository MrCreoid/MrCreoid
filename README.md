## `~/about`

I'm a developer who likes the space where **engineering meets design**.

I like taking complicated ideas and turning them into things that feel simple.

I'm especially interested in:

```text
┌──────────────────────┐
│ FRONTEND             │  interfaces · interaction · motion
│ AI                   │  tools · workflows · experimentation
│ SECURITY             │  MCP · trust · systems
│ PRODUCT              │  ideas → things people actually use
│ EXPERIMENTATION      │  building things just to see what happens
└──────────────────────┘
```

I care about the details most people skip.

The transition.

The interaction.

The weird edge case.

The last 2% of polish that somehow makes the whole thing feel different.
